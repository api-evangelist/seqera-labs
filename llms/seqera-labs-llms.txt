# Seqera Labs

> Seqera builds open, cloud-based software for scientific data analysis at scale. It is the company behind Nextflow, the widely used open-source workflow orchestration engine, and the Seqera Platform (formerly Nextflow Tower) for launching, monitoring, and governing data pipelines across cloud and HPC compute.

## API

- [Seqera Platform API overview](https://docs.seqera.io/platform-cloud/api/overview): REST API reference for the Seqera Platform.
- [OpenAPI specification](https://cloud.seqera.io/openapi/seqera-api-latest.yml): OpenAPI 3.0.1, 186 paths / 250 operations, version 1.181.0.
- Base URL: `https://api.cloud.seqera.io` (legacy: `https://api.tower.nf`).
- Auth: HTTP bearer — `Authorization: Bearer <access-token>` (personal access token / JWT).
- Rate limit: 20 requests/second per access token.
- GA4GH Workflow Execution Service (WES) v1 supported under `/ga4gh/wes/v1`.
