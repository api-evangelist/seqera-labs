Seqera (Seqera Labs) builds open, cloud-based software for scientific data analysis at scale. It is the company behind Nextflow, the widely adopted open-source workflow orchestration engine, and the Seqera Platform (formerly Nextflow Tower) for launching, monitoring, and governing data pipelines across cloud and HPC compute. Its product family also includes Wave (on-demand container provisioning), Fusion (a distributed file system for cloud pipelines), Data Studios (interactive analysis environments), and MultiQC. The Seqera Platform exposes a REST API (OpenAPI 3.0.1, 250 operations) plus a CLI (tw) and Python automation (seqerakit), and implements the GA4GH Workflow Execution Service (WES) standard.

**Areas:** Company · Bioinformatics · Workflow Orchestration · Data Pipeline · Scientific Computing · Nextflow · Cloud Compute · Life Sciences · Containers · GA4GH

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Seqera Labs: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
